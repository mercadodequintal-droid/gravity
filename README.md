# Gravity

App de treino de musculação (versão web, para iPhone).

**Como instalar no iPhone:** abra o link do site no **Safari**, toque em **Compartilhar** e depois em **Adicionar à Tela de Início**.

Os treinos ficam salvos só no aparelho de cada pessoa. Use o backup em Configurações.

Os arquivos deste repositório são gerados a partir do projeto do app (`tools/web.sh`); não edite aqui.
